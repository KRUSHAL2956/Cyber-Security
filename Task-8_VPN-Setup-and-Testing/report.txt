APPENDIX VPN CONCEPTS:

1) VPN: Virtual Private Network that creates encrypted tunnel between device and server.
2) Encryption: process of encoding data to prevent unauthorized access.
3) Tunneling protocols: methods used to encapsulate and encrypt data (OpenVPN, WireGuard, IKEv2).
4) VPN vs Proxy: VPN encrypts all traffic; proxy only redirects traffic without encryption.
5) Kill switch: feature that blocks internet if VPN connection drops to prevent data leaks.
